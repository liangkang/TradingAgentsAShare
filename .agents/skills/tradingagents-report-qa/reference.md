# TradingAgents Report QA — Reference

## Report File Layout

A saved analysis directory (from `--save-report`) contains:

```
{save-path}/
├── complete_report.md          # ← always read this first
├── 1_analysts/
│   ├── market.md
│   ├── sentiment.md
│   ├── news.md
│   └── fundamentals.md
├── 2_research/
│   ├── bull.md
│   ├── bear.md
│   └── manager.md
├── 3_trading/
│   └── trader.md
├── 4_risk/
│   ├── aggressive.md
│   ├── conservative.md
│   └── neutral.md
└── 5_portfolio/
    └── decision.md
```

## complete_report.md Structure

Generated by `tradingagents/reporting.py` → `write_report_tree()`.

| Section | Content |
|---------|---------|
| I. Analyst Team Reports | Market, sentiment, news, fundamentals analyst outputs |
| II. Research Team Decision | Bull researcher, bear researcher, research manager synthesis |
| III. Trading Team Plan | Trader action proposal (Buy/Hold/Sell, position size) |
| IV. Risk Management Team Decision | Aggressive, conservative, neutral debators |
| V. Portfolio Manager Decision | Final rating and actionable decision |

## Portfolio Manager Markdown Format

From `tradingagents/agents/schemas.py` → `render_pm_decision()`:

```markdown
**Rating**: Hold

**Executive Summary**: ...

**Investment Thesis**: ...

**Price Target**: 150.0        # optional

**Time Horizon**: 3-6 months  # optional
```

### Rating Scale

| Rating | Meaning |
|--------|---------|
| Buy | Strong conviction to enter or add |
| Overweight | Favorable outlook, gradually increase exposure |
| Hold | Maintain current position |
| Underweight | Reduce exposure, take partial profits |
| Sell | Exit or avoid entry |

## Path Resolution Examples

```bash
# Explicit path
/report-qa ./reports/NVDA_20260802_143000/complete_report.md

# Search latest NVDA report in cwd
ls -td reports/NVDA_*/complete_report.md | head -1

# Default logs location (section files only during run)
~/.tradingagents/logs/NVDA/2026-08-02/reports/final_trade_decision.md
```

Note: section dumps under `~/.tradingagents/logs/` are written during the run but the full `complete_report.md` requires `--save-report` (or interactive save prompt).
